# 1.集合概述(2023.07.20)

数组其实就是一个集合，集合实际上就是一个容器，可以用来容纳其它类型的数据

**集合为什么说在开发中使用较多？**

集合是一个容器，是一个载体，可以一次容纳多个对象，在实际开发中，假设把这10条记录查询出来，在Java程序中会将10条数据封装成10个Java对象，然后将10个Java对象放到某一个集合当中，将集合传到前端，然后遍历集合，将一个数据一个数据展现出来

**集合不能直接存储基本数据类型，另外，集合也不能直接存储Java对象，集合中存储的都是Java对象的内存地址，集合中存储的都是引用**

**集合里面可以套集合**

集合在任何时候存储的都是“引用”

集合在Java中本身是一个容器，是一个对象

## 1.3、在Java中，每一个不同的集合，底层会对应不同的数据结构，往不同的集合中存储元素，等于将数据存放到了不同的数据结构当中。

**什么是数据结构？**

数据存储的结构，就是数据结构，不同的数据结构，数据存储的方式不同（数组，二叉树，链表，哈希表，图等）

## 3.Iterator()迭代器方法

**迭代器对象中的两个常用方法**

*起初迭代器不指向集合中的任何元素，指向的是集合第一个元素前面的空*

boolean hasNext() //如果仍有元素可以迭代，则返回true

Object next()//返回迭代的下一个元素，这个方法让迭代器前进一位，并且将指向的元素返回（拿到）

**当集合的结构发生改变时，迭代器必须重新获取，如果还是用以前老的迭代器，会出现异常**：

``` java 
Collection c = new ArrayList();
Iterator it = c.iterator();//此时获取的迭代器，指向的是集合中没有元素状态下的迭代器
//注意，只要集合的状态发生改变，迭代器必须重新获取
//当集合的结构发生了改变，迭代器没有重新获取时，调用next()方法时,会出现异常
c.add(1);
c.add(2);
c.add(3);
while(it.hasNext()){
	Object o = it.next();//异常
    System.out.println(o);
}
```

删除元素时，不要使用集合的remove方法删除元素，要使用iterator自带的remove方法，使用集合的remove，改变了集合的状态，但iterator中的快照元素还未改变，不一致，会异常

# 3. ArrayList集合初始化容量及扩容



ArrayList集合底层是一个Object[ ]数组，

集合默认初始化容量是10

ArrayList集合的扩容：

增长到原容量的1.5倍，

ArrayList集合底层是数组，怎么优化？

尽可能减少扩容次数，因为数组扩容效率比较低，建议在使用ArrayList集合的时候，预估计元素的个数，给定一个初始化容量。

**扩展知识：**

\>>  该符号表示，二进制右移

\<<  该符号表示，二进制左移

数组优点：检索效率高（每个元素占用空间大小相同，内存地址是连续的，知到首元素内存地址，然后知到下标，通过数学表达式算出元素的内存地址，所以检索效率最高）

缺点：随机增删元素效率较低

向数组末尾添加元素，效率很高，不受影响

**面试官常问问题：**

这么多集合中你使用哪个集合最多？

答：ArrayList集合，因为往数组末尾添加元素，效率不受影响，另外，查询查找某个元素使用最多，效率也最高

# 11. 哈希表数据结构

1.哈希表是个怎样的数据结构？

结合了数组（查询效率高）和单向链表（增删效率高）的优点

但没有纯数组的查询效率高，没有单向链表的增删效率高

2.在此解释HashMap集合的key，为什么无序不可重复

无序：因为不一定挂到哪个单向链表上

不可重复：equals方法保证HashMap集合的key不可重复。（如果key重复了，value会覆盖）

放在HashMap集合key部分的元素其实就是放到HashSet集合中了，

所以HashSet集合中的元素也需要同时重写hashCode（）+equals方法

同一个单向链表上所有的hash值相同，因为他们的数组下标是一样的，但同一个链表上的k和k的equals方法肯定返回的是false，都不相等，

3.如果hashcode方法在重写的时候返回一个固定值的话

假设将所有的hashcode方法返回的值固定为某个值，那么会导致底层哈希表会变成纯单向链表。这种情况我们称为，散列分布不均匀

4.什么叫散列分布均匀？

100个元素，10个单向链表，那么每个单向链表上有10个节点，这是最好的

5.假设所有的hashcode方法返回的值都设定为不一样的值，哈希表就变成一维数组了，没有链表的概念了，也是散列分布不均匀

**重点：放在hashmap集合key部分的元素，以及放在hashset集合中的元素，需要同时重写hashcode和equals方法**

# 13. TreeSet

TreeSet对String是可排序的

1.TreeSet集合底层实际上是一个treemap

2.treemap集合底层是一个二叉树

3.放到TreeSet集合中的元素，等同于放到TreeMap集合的key部分了

4.treeset集合中的元素：无序不可重复，但是可以按照元素的大小顺序自动排序

称为：可排序集合

TreeSet不可对自定义类型排序

TreeSet集合采用的是中序遍历，

iterator迭代器采用的是中序遍历方式（左根右）
