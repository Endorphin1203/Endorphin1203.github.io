## 自动拆箱：


``` java
Integer z = 1000;

        方法去的“整数型常量池”当中了，目的是只要用这个区间的数据不需要再new了，直接从整数型常量池中取出来
         */
```

## StringBuilder 与 StringBuffer的区别

StringBuffer中的方法都有synchronized 关键字修饰，表示StringBuffer在多线程环境下运行时安全的

StringBuilder中的方法都没有，是非线程安全的。



## 面试题：String为什么是不可变的？

答：我看过源代码，String类中有一个byte[ ] 数组，这个byte[] 数组采用了final修饰，因为数组一旦创建长度就不可变，并且被final修饰的引用，一旦指向某个对象之后，不可再指向其他对象，所以String是不可变的（abc，无法变成abcd）

## 2 .StringBuilder 和StringBuffer为什么是可变的呢？

答：我看过源代码，它们的内部实际上是一个byte[ ]数组，这个byte数组没有被final修饰，他们的初始化容量我记得应该是16，当存满之后会进行自动扩容，底层调用了数组拷贝方法，System.arraycopy()...是这样扩容的，所以，StringBuilder/StringBuffer适合于使用字符串的频繁拼接操作。

## 4.语法

``` java

enum Result{

```

引入 try...catch...



```java
public static Result divide(int a, int b) {
        try {//程序会先执行try中的，倘若在第一行程序运行时出现异常，程序会直接跳转到catch下，
            // 执行下面的语句，若没错，则会继续执行try中的语句
            int c = a / b;
            return Result.SUCCESS;
        } catch (Exception e) {
            return Result.FAIL;
        }
    }
}
```
