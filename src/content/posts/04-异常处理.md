# 1. 异常概述

## 异常在java中以类和对象的形式存在

## 异常的继承结构：





**不管是错误还是异常，都是可抛出的**

所有的错误，只要发生，Java就程序只有一个结果，就是终止程序的运行，退出jvm

## Object下有Throwable（可抛出的）

## Throwable下有两个分支，一个是Error（不可处理的，直接退出jvm）一个是Exception（可处理的）



## 所有的RunTimeException及其子类，都称为运行时异常

运行时异常，在编写程序阶段，可以选择处理，也可选择不处理。

子类：**NullPointException,ClassCastException,IllegalArgumentException(NumberFormatException)**

## 所有的Exception的直接子类，都叫做编译时异常

编译时异常，表示必须在编写程序的时候，预先对这种异常进行处理，如果不处理，编译器会报错

直接子类：

**ExceptionSubClass，RuntimeException**

## 编译时异常和运行时异常的区别

1.编译时异常的发生概率高；

对于一些发生概率较高的异常，需要在运行之前进行预处理



## 对异常处理的两种方式

第一种：在方法声明的位置上，使用throws关键字

第二种：使用try..catch语句进行异常的捕捉。

*举例：我是某个公司的销售员，因为我的失误，导致公司损失了1000元*

*第一种：我把这件事告诉我的领导（异常上抛）*

*第二种：我自己掏腰包把这个钱补上（异常的捕捉）*

举例：

## 编译时异常

```java
public class ExceptionTest02 {
    public static void main(String[] args)  {
        doSome();//未对异常进行处理
    }
    public static void doSome() throws ClassNotFoundException{
        System.out.println("doSome!!!");
    }
}
```

### 处理方法一：（推卸责任）

```java
public class ExceptionTest02 {
    public static void main(String[] args) throws ClassNotFoundException {//将异常上抛，抛给调用者,称之为“推卸责任”
        doSome();
    }
    public static void doSome() throws ClassNotFoundException{
        System.out.println("doSome!!!");
    }
}
```

### 处理方法二:（捕捉异常，将异常自己处理）

```java
public class ExceptionTest02 {
    public static void main(String[] args)  {
        try {
            doSome();
        } catch (ClassNotFoundException e) {
            e.printStackTrace();
        }
    }
    public static void doSome() throws ClassNotFoundException{
        System.out.println("doSome!!!");
    }
```

# 4. finally子句的使用

## 1.在finally子句中的代码是最后执行的，并且一定会执行的，即使try语句块中的代码出现了异常

**finally子句必须和try一起出现，不能单独编写**

## 2.io流在使用完后一定要关闭，不关闭是一件非常危险的事

```java
public static void main(String[] args) {
        FileInputStream f1 = null;
        try {
            f1 = new FileInputStream("D:\\wsy\\Desktp\\「影创宇宙」项目计划书.docx");
            String s = null;
            s.toString();
            f1.close();
        } catch (FileNotFoundException e) {
            e.printStackTrace();
        } catch (IOException e) {
            e.printStackTrace();
        } catch (NullPointerException e) {
            e.printStackTrace();
        } finally {//finally中的代码是一定会执行的
            if (f1 != null) {
                try {
                    //避免空指针异常，如果f1没有new成功，f1 == null，如果直接.close()会出现空指针异常
                    f1.close();   //close方法有异常，采用捕捉的方式
                } catch (IOException e) {
                    e.printStackTrace();
                }
            }
        }
    }
```

## 3.finally语句执行的顺序



```java
    public static void main(String[] args) {

        //语句的执行顺序：try-》finally-》return
        try{
            System.out.println("try...");
            System.exit(0);//退出jvm，finally语句就不会执行了
        }finally {
            System.out.println("finally...");
        }
    }
```

# 坑

```java
public static int m(){
        int i = 100;
        try{
            return i;
        }finally {
            i++;
        }
    }
```

以上代码的执行结果为：**100**

原因：

*1.Java中有这样一条规则：方法体中的代码，必须遵循自上而下顺序依次逐行执行（这是亘古不变的规则）*

*2.方法体中，return语句一旦执行，整个方法必须结束！*

# 5. final，finally，finalize的区别

final 是一个关键字，表示最终的，不变的

finally也是一个关键字，和try联合使用，使用在异常处理机制中，在finally语句块中的代码一定会执行的

public class MyStack {
    private Object[] elements ;     //这里使用object，扩大使用范围
    int index;           //栈帧

    public Object[] getElements() {
        return elements;
    }

    public void setElements(Object[] elements) {
        this.elements = elements;
    }

    public MyStack() {
        this.elements = new Object[10];
    }

    public MyStack(Object[] elements, int index) {
        this.elements = elements;    //
        this.index = index;     //栈帧
    }
    public void push(Object x) throws MyException {
        if(this.index + 1 <= 9) {        //判断栈是否已满
            this.elements[this.index + 1] = x;    //将值压入栈
            this.index = this.index + 1;      //栈帧 + 1
            System.out.println("压栈成功，栈帧指向" + index);
        }
        else {
            throw new MyException("栈已满，压栈失败！");

        }
        System.out.print("栈内元素有：");
        for (int i = 0; i <= this.index; i++) {
            System.out.print(this.elements[i] + " ");       //输出栈内元素
        }
        System.out.println();
    }
    public Object pop() throws MyException {
        if(this.index != -1){        //判断栈是否为空
            this.elements[this.index] = null;       //将栈顶元素置空
            this.index = this.index - 1;      //栈帧 - 1
            System.out.println("弹栈成功，栈帧指向" + index);
            System.out.print("栈内元素有：");
            for (int i = 0; i <= this.index; i++) {    //输出栈内元素
                System.out.print(this.elements[i] + " ");
            }
            System.out.println();
            if(index == -1){
                return null;
            }
            else return elements[index + 1];      //返回当前栈顶元素

        }
        else {
            throw new MyException("栈已空，弹栈失败！");
        }
    }

    public static void main(String[] args) {

        MyStack m1 = new MyStack(new Object[10],-1);
        try{
        m1.push(10);

        m1.push(6);
        m1.push(88);
        }catch(MyException e){
            System.out.println(e.getMessage());
        }
        
        try{
            Object a = m1.pop();
        m1.pop();
        m1.pop();
        m1.pop();
        m1.pop();
        m1.pop();
        m1.pop();
        m1.pop();
        m1.pop();
        m1.pop();
        m1.pop();
        m1.pop();
        }catch(MyException e){
            System.out.println(e.getMessage());
        }
    }
}
