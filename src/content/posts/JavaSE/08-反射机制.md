# 1. 反射机制概述

## 作用：

通过java语言中的反射机制，可以操作字节码文件。（优点类似于黑客，可以读和修改字节码文件）

可以让程序更灵活

java.lang.reflect.*;

## 反射机制相关的重要的类有哪些？

java.lang.Class 、、代表字节码文件

java.lang.reflect.Method、、代表字节码中的方法字节码

java.lang.reflect.Constructor、、代表字节码中的构造方法字节码

java.lang.reflect.Field、、代表字节码中的属性字节码

```java
//java.lang.Class
public class User{
    //Field   java.lang.reflect.Field
    int no;
    //Constructor   java.lang.reflect.Constructor
    public User(){
        
    }
    public User(int no){
        this.no = no;
    }
    //Method   java.lang.reflect.Method
    public void setNo(int no){
        this.no = no;
    }
    public int getNo(){
        return this.no;
    }
}
```

## 获取一个文件的绝对路径

```java
public class IoPropertiesTest01 {
    public static void main(String[] args) {//获取一个文件的绝对路径
        InputStream path = Thread.currentThread().getContextClassLoader().getResourceAsStream("classinfo2.properties");
        Properties p = new Properties();
        try {
            p.load(path);
        } catch (IOException e) {
            e.printStackTrace();
        }
        try {
            path.close();
        } catch (IOException e) {
            e.printStackTrace();
        }

}
```

# 2. 线程的sleep方法

Thread.sleep方法可以做到这种效果：

​	间隔特定的时间，去执行一段特定的代码，每隔多久执行一次

```java
public static void main(String[] args) {
        //让当前线程进入休眠，睡5秒
        //当前线程是主线程
        try {
            Thread.sleep(1000*5);
        } catch (InterruptedException e) {
            e.printStackTrace();
        }
        System.out.println("hello world");
        for (int i = 0; i < 10; i++) {
            System.out.println(i);
            try {
                Thread.sleep(1000);
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
        }//效果
    }
```

## 终止线程的睡眠（如何叫醒一个正在睡眠的线程？）

interrupt()

```java
public class ThreadTest05 {
    public static void main(String[] args) {
        Thread t = new Thread(new MyRunnable1());
        t.start();
        try {
            Thread.sleep(1000*5);
        } catch (InterruptedException e) {
            e.printStackTrace();
        }
        t.interrupt();
    }

class MyRunnable1 implements Runnable{

    @Override
    public void run() {
        try {
            Thread.sleep(1000*60*60*24*365L);
        } catch (InterruptedException e) {
            e.printStackTrace();
        }
        System.out.println("程序结束！");
    }
}
```



## 合理终止线程的执行：

```java
public class ThreadTest06 {
    public static void main(String[] args) {
        Runnable2 r = new Runnable2();
        Thread r1 = new Thread(r);
        r1.setName("线程1");

        } catch (InterruptedException e) {

class Runnable2 implements Runnable{

    @Override
    public void run() {
        for (int i = 0; i < 10; i++) {

                    e.printStackTrace();
                }
                System.out.println(Thread.currentThread().getName() + ":" + i);
            }else {
                return;
            }
        }
    }
}
```

# 3. 关于Java中自带的类加载器

## 1.什么是类加载器？

专门负责加载类的命令/工具

ClassLoader

## 2.jdk中自带了三个类加载器

启动类加载器：rt.jar

扩展类加载器：ext/*.jar

应用类加载器：classpath

## 3.举例

假设有这样一段代码：

```java
String s = "abc";
```

代码在开始执行前，会将所需要的类全部加载到jvm当中，通过类加载器加载，看到以上代码，加载器会找到String.class文件，找到就加载，

首先，通过“启动类加载器”加载，

**启动类加载器专门加载rt.jar下的类，都是jdk最核心的类库**

如果通过“启动类加载器”加载不到的时候，

这时，会通过“扩展类加载器”加载。

**扩展类加载器专门加载ext/*.jar下的类**

如果“扩展类加载器”未加载到，

那么，会通过“应用类加载器”加载

**应用类加载器专门加载：classpath中的类**

# 5. 通过反射机制访问对象属性

## 掌握：

怎么通过反射机制访问一个java对象的属性？

给属性赋值set

获取属性的值get

```java
public class ReflectTest04 {
    public static void main(String[] args) throws Exception {
        Class c1 = Class.forName("com.tyust.javase.bean.Student");
        Object o1 = c1.newInstance();
        Field f1 = c1.getDeclaredField("no");
        //三要素依旧不可少：o1对象，no属性，值22
        f1.set(o1,2222);
        System.out.println(f1.get(o1));//private,protected修饰的不行

        Field f2 = c1.getDeclaredField("name");
        f2.setAccessible(true); //打破封装(反射机制的缺点)
        f2.set(o1,"wsy");
        System.out.println(f2.get(o1));

    }
}
```

# 7. 反射Method

```java
public class ReflectTest06 {
    public static void main(String[] args) throws Exception{
        Class c1 = Class.forName("com.tyust.javase.bean.UserService");
        Method[] m = c1.getDeclaredMethods();
        for (Method mtd : m) {
            System.out.println(Modifier.toString(mtd.getModifiers()));//获取修饰符列表
            System.out.println(mtd.getName());//获取方法名
            System.out.println(mtd.getReturnType().getSimpleName());//获取方法的返回值类型
            Class[] c = mtd.getParameterTypes();
            for (Class x : c) {
                System.out.println(x.getSimpleName());
            }
        }
    }
}
```

# 8. 通过反射机制调用方法

```java
public class ReflectTest07 {
    public static void main(String[] args) throws Exception{
        Class c = Class.forName("com.tyust.javase.bean.UserService");
        Object o = c.newInstance(); // 创建对象
        Method m1 = c.getDeclaredMethod("name",int.class,String.class);  //获取method
        Object value = m1.invoke(o,15,"wsy"); //四要素：是哪个方法，是哪个对象，实参，返回值
        System.out.println(value);
    }
}
```

**反射机制，让代码具有通用性，可扩展性强，可变化的内容都是写到配置文件（properties文件）中，将来修改配置文件之后，创建的对象不一样了，调用的方法也不同了，但是java代码不需要做任何改动，这就是反射机制的魅力**

# 9. 获取父类和父类接口

```java
public class ReflectTest09 {
    public static void main(String[] args) throws Exception{
        Class string = Class.forName("java.lang.String");
        Object o = string.newInstance();  //创建对象
        Class sclass = string.getSuperclass();   //获取string的父类
        System.out.println(sclass.getName());   
        Class[] interfaces = string.getInterfaces();    //获取父类接口
        for (Class x :interfaces) {
            System.out.println(x.getName());
        }
    }
}
```
