# 1. 多线程概述

一个进程有多个线程，

## 进程和线程的关系？

进程：火车站

线程：火车站的每个售票窗口

## 每多一个线程都会新建一个栈

多线程可以提高进程执行的效率

线程是一个进程的执行单元

堆内存 和方法区是共享的，栈内存，一百个线程有一百个栈

单核cpu只有一个大脑，不能够做到真正的多线程并发，但是可以做到给人一种“多线程并发”的感觉

# 2. 线程的sleep方法

Thread.sleep方法可以做到这种效果：

​	间隔特定的时间，去执行一段特定的代码，每隔多久执行一次

```java
public static void main(String[] args) {
        //让当前线程进入休眠，睡5秒
        //当前线程是主线程
        try {
            Thread.sleep(1000*5);
        } catch (InterruptedException e) {
            e.printStackTrace();
        }
        System.out.println("hello world");
        for (int i = 0; i < 10; i++) {
            System.out.println(i);
            try {
                Thread.sleep(1000);
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
        }//效果
    }
```

# 3. 线程调度

优先级较高的，抢占的cpu时间片更多一些

## 1.设置优先级

void setPriority(int newPriority)

int getPriority()

最低1最高10，默认5

## 2.线程让位

static void yield()让位方法

暂停当前执行的线程对象，并执行其他线程，执行此方法，会使该线程从运行状态转为就绪状态，回到就绪还可能会再次抢到cpu时间片

## 3.线程合并

void join()

例如：将某一线程合并到主线程，主线程将会进入阻塞，先执行这某一线程，直到某一线程执行完，主线程才会继续执行

# 4. 线程安全（重点）

为什么是重点？

**在以后的项目中，我们的项目都是运行在服务器中的，而服务器已经将线程的定义，线程对象的创建，线程的启动等，都已实现完了，这些代码都不需要编写**

**但你要知道，你编写的程序需要放到一个多线程的环境下运行，你跟需要知到的是这些数据在多线程并发的环境下是否安全（重点）**

## 三个条件：（满足三个条件及线程不安全）

1.多线程并发

2.在共享数据

3.共享数据有修改的行为

## 解决

**线程排队执行（线程同步机制）**，不能并发

**只有数据安全了，才可谈效率，数据不安全，没有效率的事**

线程排队会失去一部分效率，没办法，数据安全第一位

## 专业术语：

**异步编程模型**：线程之间各执行各的，谁也不需要等谁，异步编程模型就是多线程并发，（效率高）

**同步编程模型**：线程之间，线程一在执行时，必须等待线程二执行结束，或者线程二在执行的时候，必须等待线程一执行完，两个线程间发生了等待关系，这就是同步编程模型。效率较低，但较为安全

# 4. 守护线程(2023.07.26)

特点：

一般守护线程是一个死循环，所有的用户线程只要结束，守护线程自动结束

**具有代表性的是：垃圾回收线程**

```java
public class ThreadTest07 {
    public static void main(String[] args) {
        Thread t1 = new BDT();
        t1.setName("t1:");
        t1.setDaemon(true);//启动线程之前，将线程设置为守护线程
        t1.start();
        //主线程：主线程是用户线程
        for (int i = 0; i < 10; i++) {
            System.out.println(Thread.currentThread().getName() + "--->" + i);
            try {
                Thread.sleep(1000);
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
        }
    }
}
class BDT extends Thread{
    public void run(){
        int i = 0;
        while(true){
            System.out.println(Thread.currentThread().getName() + "--->" + (++i));
            try {
                Thread.sleep(1000);
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
        }
    }
}
```

# 6. 实现线程的第三种方式

实现Callable接口

这种方式实现的线程可以获取线程的返回值

**系统委派一个线程去执行一个任务，该线程执行完任务之后，可能会有一个执行结果，我们可以通过实现Callable接口，来拿到该执行结果**

```java
public class ThreadTest08 {
    public static void main(String[] args) throws ExecutionException, InterruptedException {
        FutureTask task = new FutureTask(new Callable() {
            @Override
            public Object call() throws Exception {//call方法相当于run方法
                System.out.println("call method begin");
                Thread.sleep(1000*5);
                System.out.println("call method end");
                int a = 100;int b = 200;
                return a + b;
            }
        });

        //
        Thread t1 = new Thread(task);
        t1.start();
        Object o = task.get();//可能会导致当前线程阻塞
        System.out.println("执行结束");

    }
}
```

# 7. Object类中的wait和notify方法（生产者和消费者模式）

```java
public class ThreadTest09 {
    public static void main(String[] args) throws InterruptedException {
        List list = new ArrayList();
        Producer p = new Producer(list,-1);
        Customer c = new Customer(list,0);
        Thread t1 = new Thread(p);
        Thread t2 = new Thread(c);
        t1.setName("t1");
        t2.setName("t2");
        t1.start();
        t2.start();
        Thread.sleep(100);
        t1.stop();
        t2.stop();
    }
}
class Producer implements Runnable{
    private List list;
    int i ;
boolean run = true;
    public Producer(List list, int i) {
        this.list = list;
        this.i = i;
    }

    @Override
    public void run() {
        if (run) {
            while (true) {
                synchronized (list) {
                    if (list.size() > 0) {
                        try {
                            list.wait();
                        } catch (InterruptedException e) {
                            e.printStackTrace();
                        }
                    } else {
                        Object o = new Object();
                        list.add(o);
                        this.i = this.i + 2;
                        System.out.println(Thread.currentThread().getName() + "-->" + this.i);
                        list.notifyAll();
                    }
                }
            }
        }
    }
}
class Customer implements Runnable{
    private List list;
    int i ;
    boolean run = true;

    public Customer(List list, int i) {
        this.list = list;
        this.i = i;
    }
    @Override
    public void run() {
        if (run) {
            while (true) {
                synchronized (list) {
                    if (list.size() == 0) {
                        try {
                            list.wait();
                        } catch (InterruptedException e) {
                            e.printStackTrace();
                        }
                    } else {
                        Object o = list.remove(0);
                        this.i = this.i + 2;
                        System.out.println(Thread.currentThread().getName() + "-->" + this.i);
                        list.notifyAll();

                    }
                }
            }
        }
    }
}
```
