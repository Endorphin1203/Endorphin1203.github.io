## 1.FileOutputStream

```java
public static void main(String[] args) {
        FileOutputStream f = null;
        try {
//            f = new FileOutputStream("D:\\wsy\\Desktop\\111.txt");//文件不存在的话会自动新建

            f = new FileOutputStream("D:\\wsy\\Desktop\\123.txt",true);//源文件存在的话，需要在形参后加true

            e.printStackTrace();

            e.printStackTrace();
        } finally {
            if (f != null) {
                try {
                    f.close();
                } catch (IOException e) {
                    e.printStackTrace();
                }
            }
        }
    }
```

# 2. 文件复制

先从硬盘读到内存中，再从内存写到硬盘中（**但是是边读边写**）

```java
 public static void main(String[] args) {
        FileInputStream f1 = null;
        FileOutputStream f2 = null;

        try {
            f1 = new FileInputStream("D:\\wsy\\Desktop\\134.txt");
            f2 = new FileOutputStream("E:\\nn\\111.txt");

            byte[] b = new byte[f1.available()];
            int count = 0;
            while ((count = f1.read(b)) != -1){
                f2.write(b,0,count);
            }
            f2.flush();
        } catch (FileNotFoundException e) {
            e.printStackTrace();
        } catch (IOException e) {
            e.printStackTrace();
        } finally {//这里要分开try，因为第一个有异常的话，下面的文件关不了了
            if (f1 != null) {
                try {
                    f1.close();
                } catch (IOException e) {
                    throw new RuntimeException(e);
                }
            }
            if (f2 != null) {
                try {
                    f2.close();
                } catch (IOException e) {
                    throw new RuntimeException(e);
                }
            }
        }
    }
```

# 3. IO流

通过IO流可以完成硬盘文件的读和写

## IO流的分类？

分类方式一：

按照流的方向进行分类

以内存为参照物，往内存中去，叫做输入（读）；

从内存中出来，叫做输出（写）；

分类方式二：

按照读取数据方式的不同进行分类：

有的流是按照字节的方式读取数据，一次读取1个字节byte，等于与i此读取8个二进制位

（这种流是万能的，什么类型的文件都能读取。包括：文本文件，照片，声音文件，视频文件等）

有的流是按照字符的方式读取的，一次读取一个字符，这种流是为了方便读取普通的文本文件而存在的，这种流不能读取：图片、声音，视频，word等，

.txt文件读取

**综上：流的分类：**

**输入流，输出流**

**字节流，字符流**

Java所有的流都在：Java.IO.*下

Java中主要还是研究：怎么new对象，调用流对象的哪个方法是读，哪个方法是写？

## 5.java.io流这块有四大家族

java.io.InputStream   字节输入流

java.io.OutputStream  字节输出流

java.io.Reader  字符输入流

java.io.Writer  字符输出流

**Java中只要“类名”以stream结尾的都是字节流，以reader writer结尾的都是字符流**

四大家族的首领都是抽象类abstract

**a.四个流都实现了java.io.Closeable接口，都有close方法，都是可关闭的**

**b流毕竟是一个管道，这个是内存和硬盘之间的通道，用完事之后一定要关闭，不然会耗费（占用）很多资源，养成好习惯，用完一定要关闭**

**b.所有的输出流都实现了：java.io.Flushable接口，都是可刷新的，都有flush方法，养成一个好习惯，输出流在最终输出之后，一定要记得flush（），刷新一下，这个刷新表示将通道/管道当中剩余的未输出的数据强行输出完（清空管道）刷新的作用是清空管道**

*如果没有flush（）可能会丢数据，数据部分未写入到硬盘中*

# 9. IO + Properties联合使用

**非常好的设计理念：**

以后经常改变的数据，可以单独写到一个文件中，使用程序动态读取

将来只需要修改这个文件里的内容，java代码不需要改动，不需要重新

编译，服务区也不需要重启就可以拿到动态的信息

*类似于以上的机制的文件被称为配置文件*

并且当配置文件中的内容格式是：

key1=value

key2=value

的时候，我们把这种配置文件称为属性配置文件，

*java规范中有要求，属性配置文件建议以.properties结尾，但不必须*

属性配置文件的key重复的话，value会自动覆盖
